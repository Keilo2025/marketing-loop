# Diagnostics

Marketing-loop diagnoses strings from the configured source catalogue only. It never reads application code or target locales.

- `generic-cta`: name the reader's deliverable, not click mechanics.
- `feature-not-benefit`: state the reader outcome, using catalogue context and approved claims only.
- `company-centric`: lead with the reader, not the seller.
- `unhelpful-error`: include a recovery action.
- `hype-vocabulary`: remove unfalsifiable adjectives.
- `no-specificity`: use approved claims, marketing data, or a `NEEDS-FACT` question; never infer facts from code.
- `no-problem-named`: state the recognisable situation before the solution.
- `headline-too-long`, `jargon-density`, `hedging`, `dead-empty-state`, `cta-too-long`, `passive-voice`, `exclamation`, and `no-risk-reversal`: make the source message clearer without inventing promises.

Approved source edits make translations stale. When language-loop is available, it extracts hardcoded text before marketing and translates only after marketing review and apply are complete. Marketing-loop never edits target locales.
