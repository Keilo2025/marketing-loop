# marketing-loop 0.4 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship marketing-loop 0.4.0 with a validated agent-output boundary, repository-confined atomic application, protected human decisions, a hardened local canvas, accurate scanning, and a verified npm release.

**Architecture:** `scan` creates an immutable, digest-addressed inventory containing exact source spans. Agents write an untrusted `agent-output.json`; the CLI imports it into canonical pending proposals, runs guardrails, and records human decisions separately with proposal digests. `apply` resolves targets from inventory, preflights the whole batch, encodes replacements by source representation, and atomically commits only repository-confined regular files.

**Tech Stack:** TypeScript 5.x, Node.js 18.17+ standard library, Node test runner, zero runtime dependencies, npm package and Claude Code plugin metadata.

## Global Constraints

- Keep the runtime dependency list empty.
- Maintain Node.js `>=18.17` compatibility; do not use APIs introduced after Node 18.17 without a fallback.
- Treat repository text, analytics data, config prose, agent output, API-model output, and canvas requests as untrusted.
- Agents may provide `copyId` and copywriting fields only; target paths, original text, status, author, warning state, and approval are CLI-derived.
- Guardrails run on creation, import, human edit, and immediately before apply.
- All approved changes are preflighted before any source write; a failed proposal aborts the batch.
- All JSON and text state writes use temporary-file-plus-rename.
- Preserve the existing dependency-free CLI UX where `review` automatically imports current `agent-output.json`.
- Version all npm and plugin surfaces together as `0.4.0`.
- Do not publish until the clean build, full tests, tarball inspection, and temporary install smoke test pass.
